# Telegram-бот случайных уведомлений (aiogram)

Бот задаёт пошаговые вопросы и отправляет случайные уведомления в выбранном диапазоне времени.

## Что умеет

- `/start` — мастер настройки:
  - время начала и окончания (например, 14:00–16:00),
  - количество уведомлений,
  - текст одного уведомления или список уведомлений,
  - фильтр дней (`all`, `weekdays`, `weekends`),
  - ежедневный повтор (`yes/no`),
  - формат уведомления (`text`, `emoji`, `quote`, `number`).
- `/status` — показывает текущее расписание и ближайшие уведомления.
- `/stop` — останавливает и очищает активные отправки.
- Добавляется «живая» случайная задержка ±3 минуты от рассчитанного времени.
- Настройки и запланированные уведомления сохраняются в JSON (`data/schedules.json`) и восстанавливаются после перезапуска.

## Локальный запуск

1. Установите Python 3.11+.
2. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
3. В терминале:

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
export BOT_TOKEN="ВАШ_ТОКЕН"  # Windows PowerShell: $env:BOT_TOKEN="ВАШ_ТОКЕН"
python bot.py
```

## Запуск на Render.com (для новичка)

### Шаг 1. Подготовить GitHub

1. Создайте аккаунт на GitHub (если нет).
2. Создайте новый репозиторий.
3. Загрузите в него файлы этого проекта.

### Шаг 2. Создать сервис в Render

1. Зарегистрируйтесь на [render.com](https://render.com).
2. Нажмите **New +** → **Blueprint**.
3. Подключите ваш GitHub и выберите репозиторий.
4. Render увидит файл `render.yaml` и предложит создать worker-сервис.
5. Нажмите **Apply**.

### Шаг 3. Указать токен бота

1. Откройте ваш сервис в Render.
2. Перейдите в **Environment**.
3. Добавьте переменную:
   - `BOT_TOKEN` = токен от BotFather.
4. Нажмите **Save Changes**.

### Шаг 4. Запустить

- Render автоматически соберёт и запустит сервис.
- Когда статус станет **Live**, бот работает.

### Шаг 5. Проверить в Telegram

1. Откройте вашего бота.
2. Нажмите **Start** или отправьте `/start`.
3. Ответьте на вопросы мастера настройки.
4. Проверьте `/status`.

## Важные примечания

- Это polling-бот (без webhook), для Render Worker это нормально.
- Файл `data/schedules.json` хранится на диске контейнера. На бесплатных/эфемерных окружениях Render данные могут потеряться при полном пересоздании инстанса. Для надёжного хранения в продакшене лучше использовать SQLite/PostgreSQL.
